# 个人作品主页试点记录

状态：NOT_RUN。六周从可用版本和真实参与者获准后开始，不是开发工期。以下为记录模板，空白不是 0 次使用。

按研究招募 10—12 位已有材料、近期可能发送资料的人才，覆盖导演/摄影、化妆造型等两三类主岗位；另请 3—5 位有选人经验的客户/制片做任务对照。不要只选朋友，也不要索取其客户的私人聊天或联系方式。使用匿名 participant_key / opportunity_key / task_key。

比较 A 当前实际材料、B 同等整理的原格式、C 相同内容的 ONCE 页面；固定作品、职责和项目需求并轮换观看顺序。测找职业、相关作品、本人职责、联系方式的正确率和耗时。提前选定一项高频材料任务，记录首次整理与后续更新全部人工时间（含核对、返工、支持和导出），另记模型、存储、流量及通知费用。

[独立业务机会记录](ONCE_HOMEPAGE_OPPORTUNITIES.csv)、[客户任务对照](ONCE_HOMEPAGE_TASKS.csv) 仅含列头。链接复制、二维码点击、API 读取是辅助计数，不证明真实发送或咨询；真实外用和咨询由参与者按匿名场景确认，且单独保留分母。无新作品者不计维护失败；同一次聊天重复打开不计独立机会。

研究建议的小样本决策门槛：至少 6 人真实外用、至少 4 人有独立机会重复使用；有更新机会者至少一半能自行完成；客户任务不差于原格式；事先选定任务的净人工时间中位数下降约 30%。这是待事前约定的门槛，不是行业标准或已取得的结果。分母太小则延长观察。

通过使用门槛只支持继续打磨。个人付费、收费代整理和外部团队采购分别验证真实购买选择；不把免费使用推导成付费，也不自动建设 B/C 阶段或全国人才交易平台。两轮中有足够机会却没有重复使用，再停止商业化扩展；没有机会属于证据不足。

物理 iOS/Android 微信须逐项记录设备、系统/微信版本、网络、打开、浏览、播放、再分享、联系、封面和弱网表现，单列 Web Vitals 样本条件。当前全部 NOT_RUN；匿名 Chromium 三种手机视口不能替代。
