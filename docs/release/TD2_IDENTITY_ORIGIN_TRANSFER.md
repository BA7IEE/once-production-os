# 保留身份的许可导出与重建

日期：2026-09-28。基于 `5f86a7207554e54d3a327742878b0eabba31eb28`；该提交 Actions36353019303 五条 CI 全部通过。本批新 head 另行核对。

## 实现

人物的最初来源已经删除，但完整身份字段有独立现成依据时，可显式批准保留身份导出。Person.sourceId 和用途许可的 sourceId 仍指向原始 ERASED 来源；新 retentionBasisSourceId 单独绑定当前依据。许可有效期受依据有效期约束，回执回放、后台生成和下载都重新检查范围与依据。撤销许可在依据暂停后仍可执行；删除依据也把关联许可纳入撤销。

v13 必须包含姓名、别名、简介三项及其当前同值证据，空值同样须有依据。可以迁移普通联系人，也可同时迁移职业、语言等专业资料。原来源仅携带编号、版本、安全版本及 ERASED 状态，不恢复已删内容，不允许重新启用；重建保留原来源编号与原核验归属，不复制旧用途许可或创建原账号。

页面增加“身份保留依据”选择，分别批准人物字段和独立来源字段。格式字段采用稳定排序，避免用户选择顺序与后台重读顺序不同导致导出误判变化。旧版文件继续按自身格式解析；旧冻结任务如存在不同排序内容，继续按内容变化阻断，不能绕过原摘要。

新增前向迁移 `202609280007_identity_retention_permission`，仅增加可空依据列、同工作区外键及仅限 PERSON 的约束；保留原有 Person/来源复合外键。旧许可依据为 NULL，不补造许可。该迁移已应用，之后冻结；既有40次迁移未改写。
