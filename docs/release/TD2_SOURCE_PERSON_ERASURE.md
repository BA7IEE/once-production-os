# 来源所属人物及整份专业档案删除

来源直接拥有人物身份时，影响评估现在将全部所属人物、整份专业档案、跨来源补充事实、身份证据、职业候选及代表关系纳入同一冻结图。关联人物、来源、候选清单、机构、媒体和当前范围均须可检查。每个人物和专业记录仍逐项确认；属于待删人物的资料、或依赖待删经纪人身份的代表关系不能单独保留。

专业事实、身份与专业字段证据、建议、复核项、资格及集合引用在同一事务清理。候选只失去职业时按既有规则转待核；候选随人物删除时不创建新的待核项，随后由已有关系清理器移除。删除代表关系不删除关联的其他人物。来源拥有的上传记录保持 SOURCE_UPLOAD 的强制清理决定，不会被人物媒体的可保留条目覆盖。

专业清理审计失败时整组回滚，重试后再登记逐项回执。属于本来源的原件实际销毁，其他来源的独立原件保留。最终化前失去人物范围，人物最小头与来源最小头一起回滚，申请维持 CLEANING；恢复范围后才完成。已完成删除的人物头不重复进入新申请的待删除身份列表，但最终检查仍覆盖本批人物头范围。

本次通过 CORE_MEMORY_TESTED 437/437；专项11/11、完成前范围变化专项3/3。真实 PostgreSQL 验证整份档案、跨来源身份字段、他人代表关系、资格编号、候选、审计回滚、范围变化、真实媒体销毁与独立资料保留。完整 PostgreSQL 链 DB_TESTED；真实 Chromium 逐项确认人物和专业资料、候选清除、原件销毁 BROWSER_TESTED；类型、契约、静态检查、构建 PASS，无新迁移。

原“来源所有专业档案均阻断”的测试现在改为检查明确的整人删除条目及资格记录进入计划；禁止借普通重绑来源来保留身份的断言已放入新增端到端用例，不是移除防护。真实测试库和既有迁移保留。

人物身份的有据保留仍需补齐，不能改记初始来源来冒充已完成；合并保留历史继续明确阻断。能力字典、机器身份、独立人物与无所有权的原件不随本批删除。未合并、未部署。
