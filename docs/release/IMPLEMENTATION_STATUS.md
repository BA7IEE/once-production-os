## WP2 需求锚点

FR-14/T14（部分）：姓名/角色/城市/语言/技能/状态/实际合作/核验时效使用确定性条件；“未知”不当作匹配；结果附命中依据；当前权限外的人不进入结果。行业/作品类型尚无正式字段，报价/档期明确不支持，SQL 查询下推仍待完成。

FR-15/T15（当前主链）：建立内部清单、编辑标题/需求、加入人才、选择其当前可见署名作品和该作品真实图片、排序和备注。清单不生成分享链接、客户状态或预订。依赖失效时整条候选只返回不可用占位；H1 基本档案交接不能借清单扩权。

数据约束：`shortlists`、`shortlistItems`、`shortlistItemAssets`；选图通过 `(workspaceId, workId, workAssetId, assetId)` 精确绑定 WorkAsset。WorkAsset 显式解绑时，仅派生选图关系 CASCADE，原 MediaAsset、ShortlistItem 和人才不删除。
