# AI 调用与费用账本（2026-09-28）

当前是 DEV-08 的底层实现，不是四类 AI 业务功能完成。没有新增 HTTP 路由、生产 Worker 入口或假供应商；现有应用不会因此对外发送任何资料。供应商、模型、配置文件路径、单次与每日费用上限仍待确定。

## 已实现

- PrismaStore 持久化日预算、任务预留及发送记录。金额使用同一币种的整数最小单位，日预算跨模型共用，不能靠更换供应商重置额度。原请求键与输入摘要、配置、恢复批次和金额绑定；同键异载荷拒绝，原键重放不重复占额。
- 当前事务预留预算并记录审计。发送前记录 MAY_HAVE_EXECUTED，事务成功提交后才调用适配器。网络请求不进入数据库事务；每个任务最多一条未决发送记录。
- 超时、断线、输出或落库失败进入 UNKNOWN，保留预留额；不自动重发、不换模型。取消在途任务不释放未知费用，也不生成提议。供应商迟到响应不再写提议。
- 只有有证据的 NOT_EXECUTED 才能创建下一次发送，最多三次；本批没有对外开放核对入口。已结算结果不可更换，结算重放不重复计费。确认费用超出预留会记录差额并冻结后续日期的调用；尚未开放解冻流程。
- 发起成员停用、供应商配置变化、恢复批次变化或跨日预留均阻止发送。已在途请求仍可核对费用。预算、任务、发送身份和结算记录有数据库约束；恢复检查包含账本关系和摘要。
- 调度器要求业务方提供当前事务内的授权与输入构造、严格输出验证与提议持久化。发送前和返回后都要复查；提议与结算同事务。它不会直接写正式业务事实。

账本仅保存 ID、摘要和费用状态，不保存提示词、原始资料、密钥或供应商错误正文。预留是上界估计，结算是供应商返回或人工核对的费用证据，不是供应商账单。具体计价最小单位及可信上界由后续经过验证的适配器确定；当前未配置费率。
