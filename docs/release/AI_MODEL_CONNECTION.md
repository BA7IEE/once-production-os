# 配置式模型接入

当前实现：AI SDK Core 7.0.118，OpenAI 4.0.78、Anthropic 4.0.65、OpenAI-compatible 3.0.57，全部精确锁定。直接调用管理员配置的 HTTPS endpoint，不依赖 Vercel 托管或另建网关。首版每工作区一份默认连接；更换供应商只需修改同协议配置。自定义请求头、HTTP 本地模型服务和自动模型发现未提供。

## 使用

AI 辅助整理 → 配置与费用核对 → 填写连接名称、API 地址、协议、模型名与密钥 → 保存 → 测试已保存的连接 → 刷新测试结果 → 批准当前配置。首次密钥必填，后续留空保留；密钥不回显。单次预留、每日上限、输出与超时有默认值，可在调用限制中调整。应用原有外送总开关必须允许 INTERNAL_APPROVED。

测试仅发送固定短句，不携带业务来源、字典或人才资料。测试也经持久化发送账本，占用预留。网络或响应结果未知不自动再次发送；保存未知则保留表单并原键重试。连接变更关闭旧批准，并通过版本和身份摘要阻断旧任务/用途许可。恢复后旧批准失效，需保存新的配置版本再批准。

## 边界

- 生产 worker 从 PrismaStore 读取当前工作区配置，解密密钥后调用 SDK；没有 MemoryStore 或模拟供应商回退。Config.ai 注入仍仅服务既有测试，正式配置加载器不会设置它。
- 网络位于事务外；发出前持久化唯一 attempt，当前管理员或任务发起者、来源、范围、配置在事务内重新核对。
- 三协议按显式 provider 对象选择，关闭 SDK 自动重试、遥测和原始警告；Responses 显式 store=false，不将此设置宣称为供应商零保留保证。拒绝重定向、URL凭证/查询参数，限制输出、响应字节和执行时间。
- 模型只生成白名单 JSON，原文引用仍由业务层校验；无自动工具执行、URL抓取或自动业务写入。
- 返回用量按输入/输出/缓存/推理分别记录。未知为 null，绝不当作0；无供应商响应ID时不保存SDK生成的替代ID。
- 返回建议与费用核对分开。没有实际金额时，账本保留 UNKNOWN 和预留，但已验证的建议可以人工采纳。格式错误保留用量且不生成建议。当前不估算金额、不自动查账、不将 Token 当账单；费用仍可走既有人工核对。达到预留上限会阻断新调用。
- 秘密使用既有服务器32字节密钥、AES-GCM及连接/工作区专属AAD加密；普通回执只含ID/版本，审计不含密钥或请求正文。恢复检查解密可用性。普通专业资料导出不包含连接密钥。
