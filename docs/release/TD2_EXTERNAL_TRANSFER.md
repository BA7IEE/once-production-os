## 已实现范围

新增第十个显式分组 `person.td2.personExternalRefs`，包含平台、命名空间、标识值、签发机构、OBSERVED/VERIFIED/REVOKED 状态与核验时间，以及原记录 UUID、人物、来源、版本、创建/更新时间。仅供受许可的内部迁移，不携带账号密码、cookie 或机器凭证。

所引用机构另带原 ID、名称、类型、来源、状态和版本/时间；共享机构只出现一次，不带无关机构，不导出旧范围或成员授权。重建时机构范围与其来源一样映射到目标 bootstrap 范围。当前只可导出正常可读的 ACTIVE 机构；归档、范围无权或来源不可用导致整份申请失败，不静默去掉机构。

人物许可和每个实际来源许可都必须明确批准“2.0 外部标识、核验状态及关联机构”。若机构使用另一来源，该来源也必须单独批准同一分组；人物主来源或事实来源不能代替机构来源许可。新来源进入依赖和来源清单。worker/下载复查机构可读性和事实摘要，名称/版本变化、机构范围丢失、机构来源失效或许可撤销均阻断旧文件。名称变化后可重新申请新快照。

外层保持 `once-export-v2-talent`，选外部标识时内层使用 `once-talent-transfer-v3`。未选该分组仍输出原八类 v1 或含能力的 v2，不添加空机构清单/外部标识表，不使无关标识变化影响旧文件摘要。

## 重建规则

沿用隔离空目标与真实 CLI，先预检再同事务写入机构、定义、事实及审计。机构保留原编号和来源，不虚构历史审批人。已核验状态必须带合法核验时间；未核验状态不能夹带核验时间；已撤销状态保持撤销，不重新参与标识解析。非撤销记录的平台/命名空间/机构/标识组合全图唯一，不按同一账号自动合并人物；已撤销历史与现用标识可以共存。

严格拒绝缺机构、缺机构来源、无关/重复机构、未知字段、不合法类型/长度/时间、重复现用标识。字典、机构及专业事实合计仍受 500 条上限约束。业务与审计失败全部回滚，不能遗留孤立机构。原 UUID/各字段/来源/核验状态在往返后比对。
