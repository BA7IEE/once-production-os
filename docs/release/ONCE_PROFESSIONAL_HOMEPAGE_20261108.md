## 实施说明

- `ProfessionalHomepage` 保存固定随机地址、本人归属和加密选择草稿；`HomepageVersion` 保存不可变加密公开投影和来源/署名/媒体依赖。数据库拒绝改写版本、地址、归属，只有审核删除计划能清除密文。清除后原地址永久失效，本人可用剩余已确认作品建立新地址；普通下架/重发仍保留原地址。原始授权保留为不可变归属证据，发布版本另绑定当前确切的本人授权，重新获准后可继续原地址，不使旧版本复活。
- 所有新增写入沿用本人会话、CSRF、当前授权、CAS、幂等键与可读回执。预览指纹覆盖所选事实、职责、字段和实际媒体身份，发布时重新构建并比对，源资料在预览后变化必须重新预览；公开同意绑定完整发布内容摘要。丢失发布响应后，刷新只读核对原请求，不重复发布。主页和资料维护使用各自仅含账号/请求编号的待核对标记，返回资料页不会消费主页回执。
- 公开主页单独加载约 193 kB 的 JS（压缩前，含 React），避免加载约 2.3 MB 的内部管理模块；这只是构建体积，不冒充移动网络 Web Vitals 实测。
- HTML 标题/OG 元数据从当前公开白名单生成并转义，未发布/下架时 HTTP 404。微信分享封面效果继续需实机。
- 删除评估覆盖草稿与全部公开历史，冻结指纹检查和最终化兜底拒绝旧计划遗漏；恢复摘要包含新表并校验密文，恢复时下架。尚无完整主页业务迁移格式，关联人物/作品导出及人物合并明确阻断，不静默丢失。
