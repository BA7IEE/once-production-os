开发基线为主分支 `6aeaab51565699ce8b9f5a830e13d5d706a09ed0`。原工作目录仍在 `1ba170e`，其中原有未提交测试产物未动；改造在独立 `codex/admin-product` 分支进行。本文只记录这次实现，不沿用历史测试通过数。没有数据库迁移，没有修改既有 54 次迁移，没有部署到现有预览或正式环境。

## 本次可操作的改动

- 侧栏按日常工作、工具与协作、系统设置分组，工具和设置默认收起。按既有权限过滤入口，账号区域独立。
- 工作台提供新增人才、查找人才、整理作品、记录项目入口。删除固定开发版本装饰，统计口径继续沿用原接口。
- React Router 的稳定页面地址：工作台、人才、作品、项目、候选、素材、工具和设置。人才、作品、项目和候选均有详情地址；服务器只为明确登记的页面回退 HTML，API 和媒体地址不参与回退。
- 人才列表使用人才 2.0 查询，支持表格/卡片、现有专业筛选、分页；兼容视图保留旧档案与交接资料。正文检索条件只在当前身份的内存中保留，退出和身份失效时清空。
- 新增入口收敛为“新增人才”。在同一页记录新来源或分页选择已有来源；普通联系人通过次级选项登记。来源回执成功后继续使用原来源，人物结果未知时保留原键并锁定输入。建档后进入同一人物的专业资料分区，职业和素材继续按各自命令保存。
- 人才详情按基本资料与来源、专业资料、照片与附件、作品与项目分区；专业资料分类可用 URL 定位。交接访问仍只进入受限基本档案，不强取人才 2.0 或媒体。
- 作品与项目支持名称/状态筛选及表格/卡片；项目默认表格，作品默认卡片。既有署名、参与阶段、关联类型、维护任务和语言文本保留。
- 人才/作品列表增加 `coverAssetId: string | null` 只读摘要。人才只取当前可用集合中明确推荐的图片，作品只取当前封面对应的可读图片；均不返回完整关联。来源、范围或素材权限不满足时为 null，预览请求继续独立鉴权。
- 来源选择补入人才建档和媒体上传分页，导入来源及候选清单列表也有分页。机构与品牌有独立入口，机构登记复用旧命令；品牌登记/修改保留来源、版本及不可见机构不被空值覆盖的规则。
- 路由离开与浏览器关闭检查未保存表单。人才、作品与项目检索条件不作为未保存业务表单。已有全局未决命令入口保持挂载，传输层未被重写。

## 依赖及安全适配

锁定 `antd 6.6.5`、`@ant-design/icons 6.3.4`、`react-router 7.18.4`。组件样式使用 Ant Design 的预编译 CSS；仍需动态样式的组件通过每次 HTML 请求独立生成的 style nonce 适配现有 CSP。`script-src 'self'` 不变，没有新增 `unsafe-inline`。

`@rc-component/util 1.13.0` 的滚动条测量样式未传递 CSP nonce，真实浏览器已复现。`patches/` 中的锁定补丁只让该样式读取页面的 nonce，不扩大脚本权限；升级该依赖时必须重新检查补丁和 CSP 浏览器断言。其余业务写入继续走原 `call/read`、CSRF、幂等及账号绑定逻辑。

官方参考：[Ant Design 样式与零运行时模式](https://ant.design/docs/react/customize-theme/)、[React Router 导航拦截](https://reactrouter.com/api/hooks/useBlocker)。官方支持说明不是本仓库的兼容验收；结果以本次实际运行记录为准。
