# 共享图片与证明引用清理

ASSET 删除现在明确评估专业作品集、资质附件、成年资格证明和待审建议；有编辑外范围依赖时阻断。人工确认并冻结计划后，同一事务移除目标图片的集合引用、重排其余图片、撤销相关资质当前状态、将成年资格改为未知、使相关待审建议失效，再交由原物理清理流程销毁原件及预览。

保留其他图片、集合类型/标签、人物其他专业事实、受限编号及原字段核验历史。保留的原核验人和时间只是历史，不能在原件删除后继续证明当前资格。建议失效记录处理时间与本次清理发起者，不冒充审核采纳。

## 人工操作与防错

删除影响页显示实际集合引用、资质、成年资格和待审建议数量。该项必须明确确认；不能选“删除原件但保留有效引用”。若原件需要保留，应在启动删除前停止该流程。一般集合移出仍只删除单处关联，不删除原件。

冻结摘要绑定引用内容、集合顺序、相关专业事实、字段证据、待审建议、人物范围与来源。任何漂移都拒绝旧计划。执行时再次检查相关范围；依赖清理、文件清理和最终化均检查发起者当前账号状态、删除权限、根对象/原来源范围及租约，冻结计划不构成永久授权。

专业引用修改与清理审计、回执同事务；失败全部回滚，同一计划可在限次内重试。实际文件操作在数据库事务外，原有物理清理与最终化边界保留。清除全部当前引用后才能执行原件清理；新出现的未知类型依赖不能被忽略。
