# 素材清理待核对：本人提示与增量验收

基线为 PR #41 的 `4ff15434654ea6467dbfff296fafc86f2cf70a5a`。本次改动在本人有权访问的资料中，对已移除且清理结果为 `DELETE_UNKNOWN` 的素材返回脱敏 `cleanupState: CHECK_REQUIRED`；内部审核资料不增加该字段。本人页面提示清理结果待核对、确认前仍占额度；已清理 (`ERASED`) 的素材行不再落入“处理中”的通用显示。没有将 UNKNOWN 解释为物理删除成功。

额度文案对照 `MEDIA_ADMISSION_DEFAULTS`、只允许收紧的配置以及 `createTalent` 对未设置 `purgedAt` 的上传计数。完成清理后由现有事务将 `purgedAt` 设置并将 `expectedBytes` 归零，界面不保留该素材的待核对或处理中行。

在独立临时 PostgreSQL、真实 Nest API 和 Chromium 上运行增量任务：本地 COS SDK 替身触发 UNKNOWN，本人刷新、重新进入、双击与请求重放后保持状态和额度，匿名及另一合成账号不能读取资料；返回字段白名单不含对象 token、清理租约和存储路径。1366×768 下完成小文件上传，Chromium 原生 200% 页面缩放下（683×384 CSS 像素）提示与键盘移除可达。另一个合成素材使用真实本地文件系统提供方完成清理，确认原 UNKNOWN 素材仍待核对、占用额度，新素材的已清理行消失。只对隔离数据库中的测试素材提前保留期限，没有等待自然经过七天。临时数据库、进程、浏览器及目录按 ResourceRun 登记并回收。

复用上一轮相关核心测试 35/35 和浏览器记录，并对新增字段、本人/其他账号/内部审核边界及清理完成状态执行专项回归。契约生成器核对的是请求 schema；返回字段及权限由专项测试与实际 HTTP 验证。最新测试脚本为 `scripts/test-cos-unknown-ui-20261110.mjs` 及对应 `tests/acceptance/browser-cos-unknown-ui-20261110.mjs`；过程截图、HTTP/DB 摘要、日志和资源记录存于本次隔离工作区的验收证据目录，不含真实资料。

真实 COS、真实认证供应商和物理手机仍为 NOT_RUN；COS 自动最终核对闭环没有由本测试证明。真实供应商测试需要明确获准的测试租户与账号、独立存储桶或前缀、可控测试接收通道及操作/费用边界；不使用生产业务资料。此本地整改不代表远端 CI、合并或部署。
