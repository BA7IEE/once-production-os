# 来源专业事实逐项处置

来源拥有人物专业事实时，影响预览列出本来源资料及依赖这些资料的跨来源下级关系。人工为每项选择“删除这项专业资料”或“有独立依据，保留”，并确认整组执行。清理页重新检查范围后显示人物、职业/语言/集合及有效期等必要识别信息，不显示受限编号。

保留必须已有覆盖全部注册字段的有效独立证据，包括空值和时间边界；所选保留来源必须实际支持该资料当前字段。不能仅填另一个来源就保留，也不能删掉有效期来扩大资格。保留事实的稳定UUID、原sourceId及其他来源原核验归属不变。原sourceId在本来源删除后表示历史来源，不表示它仍有效。

删除上级资料时，下级资料也需逐项决定。保留下级但删除其职业、集合、量尺或专业主档案时拒绝冻结。删除职业保留候选编号、备注与作品历史，将角色置为待核实并建立明确复核记录，不猜职业。集合删除只移除其组织关系，不删除其他来源原件。

所有资料处置在单个事务内执行，连同审计失败全部回滚；各决定槽仅在整组成功后记录完成。冻结摘要包括原事实、证据、建议、集合关联、候选与复核、上级/机构/代表/图片/作品及其来源和范围。做决定、冻结、开始和执行均重新验证；范围变化和字段更新拒绝旧计划。最终化逐项确认保留收据、完整依据与原事实摘要，不能靠放宽全局依赖计数来忽略遗留关系。
