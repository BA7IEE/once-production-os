# 后台 UI UX 改造交付

授权：2026-10-04 用户要求“直接落地”整份后台解决方案。基线：PR #36 / `ccfe1406a77788fa01cb15290e4ccceb6b8fa382`。分支：`codex/admin-ux-solution`，叠加到 `codex/business-flow-fixes`，保持 Draft。没有合并、部署、新迁移或新增依赖；75次迁移保持原样。

## 当前实现

- 六个日常入口及收起的管理分组；工作台展示当前权限下的待办和近期档案。
- 人才库以照片结果为主，保留全部筛选维度；勾选与打开详情分开，跨页选择及返回保留上下文。
- 人才详情分为概览、基本资料、照片视频、作品与合作。姓名、个人资料、模特分类、量尺、联系方式和专业记录在对应区域维护；个人资料、模特分类和专业记录可就地补充其他来源的修改建议，原值经明确审核后才更新；邀请和团队核验携带当前人才。不可读的个人资料和模特分类字段不展示编辑控件，也不会被默认值覆盖，保存只包含实际改动的可读字段；出生信息不可读时，仍可保存其他可读资料。
- 候选清单使用显式清单、范围与职业选择；整批验证后提交，重复项单独报告，不发生部分新增。清单容量100条，单批最多100项，选择上限200项；可明确移出暂不处理项，提交成功只清除本批处理过的选择。
- 照片页优先展示已有素材，按需展开上传。多文件顺序上传，资料摘要刷新不会重建队列；未知响应或异常成功响应暂停后续文件；只读核对后明确继续，不重复发送已接收文件，成功文件保留。媒体集合和本人作品可在当前档案选择素材及补充上传。
- 新作品命令在同一事务记录案例、具体职业署名、来源、素材顺序和封面。保留未知日期，任一项失效整批回滚，使用现有作品生命周期。作品与项目使用完整页面和稳定地址，刷新、返回不丢失记录上下文。
- 审核聚合本人文字/媒体提交、归属申请、来源核验和外部材料，按本人待办、本人发起和已处理组织；选择审核组会同时选择所需项目，取消时连同依赖项取消。失效归属申请的列表与详情状态一致，隐藏批准入口，保留明确拒绝尚未处理申请的动作。
- 表格/CSV导入先对应字段，再服务器逐行预览、明确提交并查看真实后台结果；未知名称不猜测、不自动合并。旧JSON导入和历史修复保留在高级入口。
- 未保存内容仅在内存保护，不持久化正文。结果未知时冻结原输入，提供只读回执检查和独立的原样重试。读取和命令都绑定当前成员，身份变化清除旧显示。

使用现有React/native控件和一致的布局样式，未引入另一套组件依赖或改变业务权限。设计参考及规则见[整体方案](../design/ADMIN_UX_SOLUTION_20261004.md)。

## 验收与边界

前批实施期间，本机 Swap 超过项目4GiB门槛，该批没有运行本地构建、数据库或浏览器服务。本轮复核时资源门槛已恢复，重型验收继续统一在独立CI执行。轻量专项38/38通过，前后端类型检查通过。构建、真实PostgreSQL、真实Nest/Worker/Chromium业务链、本人端回归和本轮资源清理在新增的 `ONCE admin UX acceptance` CI 上执行。

自动化验收以 [PR #37 当前提交的检查](https://github.com/BA7IEE/once-production-os/pull/37/checks) 为准：独立 Linux runner 上的 `acceptance` 与 `core` 必须同时通过，各 runner 内的重型任务串行执行。证据 JSON 记录运行对应的提交，开始前清空旧输出，不以旧提交的成功替代本轮结果。真实供应商 **PROVIDER_VERIFIED=NOT_RUN**；无提示真人可用性测试 **NOT_RUN**。设计中的耗时/通过率是待验证目标，自动化与合成数据不证明真人使用体验或真实供应商已通过。部分读取的前端边界用受控响应投影验证，提交与数据保留则使用真实服务和数据库；该项不替代真实权限验收。

CI证据：`artifacts/admin-ux/postgres.json`、`browser.json`与1280×800、360/390/430像素截图；原业务链及本人端回归证据分别在 `artifacts/business-flow/`、`artifacts/talent-experience-pr02b/`。资源清理以本轮 `run.json` 的 `ZERO_RESIDUE` 为准。失败运行保留问题记录和截图；最终通过以当前提交及该次运行的证据为准。

新交互验收包含：首排完整卡片、跨页选择与返回、显式清单范围与职业、提交响应丢失后只读核对、去重、明确选取本批且保留未处理选择、手机键盘筛选、未保存离开保护、新来源建议与明确采纳、顺序上传与部分失败、封面、作品署名与素材一次提交、完整页面刷新、表格导入及真实后台逐行结果。另执行原业务协作链与本人维护端回归。
