SRVF 历史评估基线：`BA7IEE/srvf-nest-api` / `fc7471efadaf22834d5effb0b92a9fdd034bea2b`。历史研究与文件证据参见 [05_REUSE](../spec/05_REUSE.md) 和 [13_SOURCES](../spec/13_SOURCES.md)。

## 实际采用的复用方式

这次主要复用工程机制并独立实现 ONCE 版本，没有将 SRVF 整仓复制、统一改名或自动抽包。没有把旧 migrations、救援组织/队员/任职/考勤模型接入 ONCE，也没有改动其线上配置。

| 机制 | 当前处理 |
|---|---|
| 请求幂等与事务回执 | ONCE 自己的最小回执、当前权限复查、受限 JSON 摘要与测试 |
| 任务持久化/租约 | 按本地导入需求实现 PG 候选适配和 MemoryStore 回归，不复制旧通知渠道 |
| 范围与敏感字段 | 新建简化成员角色及资源范围，不照搬救援任职/组织树 |
| 审计 | 最小动作和字段名，不复制旧业务事件全集 |
| 存储 / AI | 尚未抽取或实现；不能写为已复用的交付功能 |

因此，本包不声称“复用了某个百分比 SRVF 代码”，也不把相似机制当作旧项目的测试通过证据。
