# 独立字段来源清理

同一字段存在多份来源时，可以删除其中一份独立来源。影响预览合并显示该来源的字段证据、建议及涉及资料数量；人工确认后，原有清理流程删除指定证据及建议，红除来源历史内容并最小化来源头。专业事实、其他来源的字段证据和原核验归属逐项不变。既有媒体、联系方式及旧导出清理仍按其原有影响项执行。

每个受到影响的字段必须已有另一份当前有效、版本匹配且值摘要匹配的登记依据；不能靠在删除页选一个来源来伪造原核验。删除最后一条证据也不能触发“回退到初始来源”的意外可见性。新方案不重绑原证据的来源/核验人。待审及已处理建议均可能含该来源载荷，随本次确认清理。

冻结摘要绑定涉及资料、全部保留证据、其他来源版本/状态、人物和来源范围。执行时重新检查发起者当前资格、范围、来源有效性、删除阻断及原核验历史约束；审计失败则证据和建议一并回滚，可按原计划重试。隐藏依赖不暴露记录编号或字段内容。
