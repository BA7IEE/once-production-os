# 候选职业选择与人工复核

候选清单明确记录本次入选职业。专业工作台可以选择已有清单，同一人物以不同职业分别加入；关联作品只显示该职业的本人署名。服务端创建、读取和复核时均重新核对作品署名及当前来源、范围、图片关系。

旧人物显式建立专业档案时，已有候选保留 UUID、备注与选图，逐项标记待核实职业，并追加复核项、提升清单版本。升级不会自动挑选职业；任一相关清单不可见或依赖超过 500 项时整批拒绝，不能部分升级。

## 操作与权限

- 人物详情 → 专业工作台 → 加入候选清单 → 选择清单及本次职业；可关联同职业作品及其图片。
- 候选工作台显示“待核实职业”；有编辑权限者核对需求后显式选择。原备注与选图在确认前不作为有效候选展示。
- 只有完整候选依赖当前可见时，编辑者才收到复核所需的姓名和职业选项；只读成员保持不透明占位。来源、作品或图片失效则不显示复核信息，也不能执行绑定。
- 人工确认可同时解决合并后保留的多个复核项；原 UUID、原因、原候选编号历史不被覆盖。不会将条目绑定成已有的同人、同职业、同作品候选。
- 响应未知锁住原表单，原请求键与请求体重试；审计失败，职业绑定、复核状态、清单版本和回执一起回滚。
