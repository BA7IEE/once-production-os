## 实际数据合同与维护

- Demographics 业务字段位于既有 `talentProfiles`：性别，EXACT_DATE / YEAR_ONLY / DECLARED_RANGE / UNKNOWN 出生分支，出生年份或声明年龄范围及声明日期，国籍声明数组和封面 Asset ID。ModelProfile 业务字段位于既有 model `personRoles`：国模/外模/未分类，素人/专业/未确认，风格与服务意愿标签。保留原 TD2 owner、字段依据、CAS、审计和提议，避免再造一套人才事实库。
- 这是存储 ADR：使用现有稳定的一对一专业档案和同角色职业行承载规范中的业务概念；没有另建第二份 Demographics/ModelProfile 主档。非 model 职业不能携带模特分类与标签。国籍与业务市场独立；风格与服务意愿不表示已拍摄经历。
- 前向迁移 `202609300001_talent_experience_pr01b` 增加列、数据库分支检查、工作空间封面外键、索引和字典种子。旧人物的新增字段仍未知，量尺旧日期/状态/历史指针不改；旧 `reportedAt` 留空。
- `MeasurementSet.measuredOn=null,datePrecision=UNKNOWN` 是明确日期分支。EXACT_DAY/APPROXIMATE 必须有真实日期。新 `reportedAt` 来自服务器接收时间，客户端不能传入或修改；确认只表示采用声明，不能据此认定测量日期已核验。
- 目标读合同标明 `once-talent-v2.1.0`；2.0 仍接受原字段和原日期语义，拒绝使用新增字段或 UNKNOWN 日期。2.0 旧提议继续按原规则复核；服务器收录时间不进入可编辑字段。
- 完整生日独立受 `sensitive.read/write` 保护，普通目录只展示安全年龄区间。生日提议和依据不可借普通权限读取。生日导出新增精确字段 `person.td2.birthDate`，人物和实际来源都须有新许可；旧专业许可不自动扩权，重建还复查目标成员实际敏感写入权限。出生信息不设置成年资格。
- 年龄按查询日期重算完整可能区间，只有整个区间符合上下限才匹配；2000 年出生在演示日期为 25–26 岁，不能当成准确 25 岁。未知不变成 0。

`PATCH /api/v1/directory/talents/{id}` 是内部组合 COMMAND，一份原键、一次事务、回执和审计，依次复用既有事实命令；冲突、不同来源、无权限或审计故障整笔回滚。只补有变化的字段；已确认量尺新增版本。主详情维护包含三围、鞋码/服装体系和日期精度。

## 查询、目录与详情

`POST /api/v1/directory/talents/search` 是严格、认证、Origin/CSRF 保护的 READ，不要求 Idempotency-Key，不产生写回执。目录和候选找人调用相同合同、同一组件。查询支持姓名、人物范围、同职业、性别、国籍、业务市场、从业类型、角色标签、城市、语言、年龄、当前量尺身高、同作品行业/类型和分页。筛选计数应用其他维度条件，逐选项执行相同匹配规则再按人数计算；演员不能借用模特分类的计数，不用行数冒充人数。

数据库适配器以绑定参数执行 SQL 初筛，加载相关人物的事实与字段依据，再经现有权限/来源图核验；数据库对核验后的 Person ID 去重计数、稳定排序与分页。SQL 初筛允许多取，最终匹配仍以现有字段依据为准，避免不同来源或不同角色借用事实。旧 GET TD2 搜索保留为兼容/对照路径。旧翻译方向、成年资格等高级机器查询以真实浏览器认证请求回归；正常页面仅使用统一目录，未保留第二个搜索弹窗。

当前核验候选和参考表仍有 50,000 条有界保护，超界明确拒绝，不伪报完整结果。没有以此宣布无限规模性能验收或最终容量交接完成。

正常目录仅一个入口；点击卡片直接进入主详情。返回保留查询、分页和选择。主详情显示当前被采用的量尺，而非任意已确认历史行；语言与外观资料、照片、作品和实际项目关系就地可见。高级管理保持原权限管理与专业审核功能，供有明确目的的维护使用。

## 五步真实演示

1. 在“人才档案”点“新增人才”，填写姓名，沿用现有快速建档；可选择多职业和已核对来源。
2. 点“补充核心资料”，填性别、仅出生年份、明确国籍，选择国模/外模、素人/专业及标签；没有资料的项保持未知。新增量尺可以选择“日期未知”，有权限并核对来源后明确采用。
3. 在同一个主详情上传照片，等待实际检查和预览，点“选作封面”并保存。演示照片是合成色块，不是被误判属性的真人照片。
4. 返回目录，用“模特＋女＋国模＋素人＋25–26 岁＋170cm 以上”组合找人，看到真实照片卡片和计数。改成准确 25 岁得到明确空状态。
5. 点卡片直接查看资料，再返回保留筛选、选择和页码；候选工作台用同一条件得到同一 Person ID。另有 21 条合成人物验证实际第二页返回。
