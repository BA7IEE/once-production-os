## 事实与权限

- 资格记录保留稳定 UUID、人物、来源、状态、有效期、创建/修改及核验时间；核验归属明确记录原 workspace 和原 membership。目标不创建原账号、不把历史核验冒充目标管理员的新批准。
- 导出成年资格需要当前 `sources.review`，并须由人物及实际来源分别批准该分组。证明文件仍须 Asset 和来源独立的 `media.originals` 许可，不是默认附赠的证件导出。
- 已有核验归属时，必须同时选择并批准字段来源证据，保留与原核验人/时间匹配的 `VERIFIED_ADULT` 状态证据。不能只带一个核验状态，丢失其依据。
- 不生成新有效期；过期、INACTIVE 和证明图片隔离后仍不能通过成年资格筛选。UNKNOWN、SELF_DECLARED_ADULT、RESTRICTED 不会因图片或集合标签被升级。
- 原核验归属仅向有 `sources.review` 的资料读取者展示。通用字段写入/建议仍不能直接设置核验结果或原核验身份。

## 目标核验与历史

目标记录 `verifiedByMembershipId=null`，使用新增的 `originalVerificationWorkspaceId` / `originalVerificationMembershipId` 保存历史归属；原 `verifiedAt` 不变。数据库拒绝半组归属、原归属与当前核验人混搭、缺少核验归属的 VERIFIED_ADULT。再次导出保留最初归属，不把重建执行者换成原核验人。

目标明确重新核验时，现行核验改为当前操作者，旧核验依然保存在迁入的字段证据历史中。核验命令现在同时追加 state、validUntil、evidenceAssetId 的依据；此前只追加 state，在重新核验改变有效期或证明时可能使字段仍指向旧证据。本批补齐这个业务写入，并测试重新核验后所有字段仍可读。真实浏览器暴露核验记录与字段证据分别取时的毫秒差异；修复为同一核验事件共用时间点，并增加持续推进时钟回归，不放宽原归属一致性要求。

恢复摘要包含新增归属字段；恢复检查同时核对原核验归属和保留的状态证据。真正的 pg_dump/pg_restore + 私有媒体恢复演练加入合成原环境核验记录并比较恢复前后完整记录。
