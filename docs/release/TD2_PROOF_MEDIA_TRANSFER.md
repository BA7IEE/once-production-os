## 行为

- `once-talent-transfer-v7` 在原 v6 资质结构上增加严格的证明原件清单：稳定 Asset UUID、来源、所属人物、原件与预览的长度和 SHA-256、尺寸与原始时间。目标重新登记私有存储位置，不输出原机器路径、upload token 或 object token。
- 带附件的未核验、已核验、撤销资质均保留附件关系；VERIFIED 必须有证明文件。凭证编号仍需独立授权、按目标密钥重新加密。旧 v1～v6 保持兼容，未选择原件权限时继续拒绝遗漏附件。
- 原件单独使用 `media.originals`，每个 Asset 和实际来源均须批准；不是普通 `media.identity` 许可的自动扩权。只导出所选资质引用的原件，同一文件多次引用只保存一份。
- 原件清单参与专业图摘要和来源/许可/范围复查。GET `/exports/{id}/media/{assetId}/original` 与 `/preview` 在读取文件前后分别复查会话与当前资格；发送前写入既有 `export.download` 审计。撤权、隔离、内容变化或审计失败都不发送文件。
- 私有文件读取检查真实目录、拒绝符号链接、核对长度及摘要；单张原件限 30 MB、预览限 5 MB，单次证明文件总量限 2 GB。文件 I/O 不占数据库事务。
- 浏览器批准图片及来源用途，下载 JSON 后逐项下载证明原件/预览。缺任何文件不得当作可完整重建的包。

## 隔离重建

沿用 `pnpm rebuild:json`、`DATABASE_URL_REBUILD` 的 loopback `once_rebuild_*` 空库限制、`ALLOW_REBUILD=yes` 和源导出 `--expected-sha256`。提供：

- `REBUILD_MEDIA_INPUT_DIR`：0700、无符号链接的独立绝对目录，文件按 `<asset UUID>.original.bin` 和 `<asset UUID>.preview.jpg` 命名。
- `REBUILD_MEDIA_TARGET_DIR`：专用于本次重建的新私有目录。不得指向现有正式媒体目录。
- 有加密资质编号时，仍需 `REBUILD_SOURCE_CONTACT_KEY_FILE` 与目标真实 `CONTACT_KEY_FILE`。

CHECK 只核对目标和输入文件，不创建目标目录。APPLY 先完成全部文件校验，再把文件写入新目录并 fsync；目录登记清单摘要和目标 workspace，重试只接受相同绑定。数据库事务重新核对空目标后，同时插入来源、身份、媒体、专业记录、证据与重建审计。

数据库失败或结果未知时保留已经准备好的私有文件，不能在 catch 中删除可能已经被提交记录引用的文件。已明确回滚后，可使用同一目录、同一文件与摘要重试；已提交目标继续拒绝覆盖。文件和数据库之间不是跨系统原子事务；本工具只用于离线隔离安装，成功后仍需维护人员按既有恢复检查流程验收环境。
