## 实现

旧候选工作台的 `/talent-search` 原来仍按 Person 历史字段做 SQL 筛选。现在混合旧/新资料的工作空间使用当前专业关系、原有来源和范围规则；职业、语言、能力、常驻地及核验时效不再来自失效的旧字段。结果总数、分页与分类计数使用同一结果集合。

行业和作品类型须匹配同一件、同一所选职业的可见署名作品；“实际合作”只计算该职业的 ACTUAL 参与。当前核验需要当前来源版本及值摘要一致；旧专业字段核验不自动变成新事实核验，未核验的普通录入也不算当前核验。

原生档案访问边界不变，基本交接仍不授权结构化检索。纯旧版工作空间保留原 SQL 路径，通过两个存在性检查选择兼容处理；没有引入生产 MemoryStore 或扩大既有查询预算。混合资料使用现有有界专业关系快照，这不代表所有规模的 P95 已验收。

另外，原量尺确认逻辑会把仅含鞋码的记录也当作已解决旧身高语义。现在只有确认记录确有身高时才解决旧身高复核。鞋码/衣码等记录仍能独立确认，但旧身高保持待核对；明确身高确认、历史量尺状态、复核状态和审计保持同事务。
