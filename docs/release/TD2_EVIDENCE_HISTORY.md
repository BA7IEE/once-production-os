# 字段依据浏览

复核成员从专业工作台进入“查看字段依据”或“查看身份依据”，选择字段，分页核对当前值是否一致、来源是否仍有效、版本是否匹配。只有三者均满足才显示“当前值有此依据”。原环境核验保留原环境、成员编号与时间，不冒充当前账号核验。

接口要求 sources.review、sources.read、records.read，拒绝机器身份。每条记录复查人物、资料和来源范围；不可见来源先过滤再分页与计数。暂停或过期来源可在当前范围内显示历史状态；被删除阻断或已清除来源不展示。只支持当前可读资料的历史，不提供越过权限的历史入口。普通读者不出现操作入口。

字段必须属于注册类型与字段白名单；返回值不包含 valueDigest、资格密文、原始字段值或来源原文。读取历史不会修改事实、来源或核验记录。当前人物基本信息编辑尚未自动产生字段证据；页面如实显示无记录，显式字段核验后才出现依据，不能把普通保存当人工核验。
