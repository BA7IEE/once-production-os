# ONCE 预览视觉问题复核

用户截图经Library受支持物化到本机后查看像素，确认属于127.0.0.1:4340的ONCE虚构预览。源图2048×989、2048×870；本机当前Chrome窗口1512×896、retina截图3024×1792，已只在本机截取当前ONCE窗口复现。截图不入Git、不上传Actions或Library。Chrome禁用Apple事件JavaScript，未启用该安全设置；精确DOM innerHeight不可读取，云端使用1512px宽及730/642px截图比例高度，明确为推导值，并保留原桌面/窄屏回归。

## 已确认问题与根因

1. 工作台、审核及其他菜单都使用同一张通用人才示例表；审核的详情仍是人才概览。根因是预览入口按菜单换标题、未使用业务页面组件。旧CI只检查按钮可点、标题存在，没有断言模块语义。
2. 预览section使用没有样式定义的card类，详情和筛选浮在整个背景上；实际页面使用panel等既有容器。
3. 顶部大块Alert占据首屏，低饱和深蓝经派生背景产生较深灰面。修复为紧凑预览说明，语义反馈背景显式锁定浅色token。
4. 筛选提交按钮与输入底边不齐，整体信息密度不适合工作台。由实际页面组件负责具体布局，共享filters在底边对齐。

## 修复与验证要求

独立预览直接使用真实WorkspaceHome、TalentDirectory/Detail、TalentIntake、ShortlistWorkbench、ProductionPanel、ReviewWorkspace。虚构只读投影仅由预览入口安装，不改变生产main/API/权限模型；所有写入、核验、凭证操作明确拒绝。未覆盖的管理模块显示范围提示，不冒充通用列表。

新增整页CI断言：工作台待办/最近入库，审核分类/归属申请详情，人才目录筛选/分区详情/返回，建档表单与拒绝写入，候选清单、作品/项目列表及刷新，说明条<=64px、主标题在首250px、空/错场景及不同桌面窄屏宽度。云端不生成截图录像，只上传JSON。下载同SHA产物后刷新本机4340，截取现有Chrome窗口复核像素；人工视觉验收继续保持待评审。
