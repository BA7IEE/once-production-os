# ONCE Production OS｜MRD｜内部用户任务与需求验证

版本：v0.3｜日期：2026-09-22｜当前范围：一期内部 OS + AI｜状态：文档已修订，产品实现和运行测试未执行

## 1. 研究重心的变化

本轮是对现有研究文档的范围修订，不是重新开展市场调查、采购询价、用户访谈或搜索量研究。此前的官方产品与SRVF证据保留在13，标为历史研究依据；本轮没有据此承诺产品当前价格或现有功能。

现在的问题是“ONCE的人如何更快组织和复用制作资料”，不再是“如何把资源库变成公开获客网络”。对外流量、公开入驻和SEO需求不用于给一期排优先级。

## 2. 当前主要用户

| 用户 | 当前所需 | 非当前所需 |
|---|---|---|
| 资源协调/制片 | 收资料、补字段、找人、比选、记项目实际参与 | 公开挂人、在线经纪交易 |
| 内部资料维护 | 作品归组、署名、来源、新鲜度、重复修正 | CMS发布审批、全球版权清点中心 |
| 业务负责人 | 看有哪些资源、何处需要核实、是否省时间 | 自动财报和完整销售管道 |
| 内部只读成员 | 看到获准的基本资料与作品 | 原始联系信息、源文件全文、AI/导出权限 |
| 技术维护者 | 日志、任务、配置、升级、恢复和可接管文档 | 多租户SaaS运营、复杂插件平台 |

模特、摄影师、剪辑师、化妆师、造型师等均是一期管理对象。一人可多工种。先用统一档案和作品职责表达；模特必要尺寸提供可选专属字段，不给每个工种重新建身份系统。

## 3. 当前任务编号

J01：接收、去重、归档和补全资料。J02：按需求找人并说明证据。J03：形成内部候选清单并交接。J04：整理作品、署名、实际项目与复盘。J05：用AI辅助提取/打标签/写中英草稿/解析检索，并人工采纳。J06：纠错、停用、到期和删除处置。J07：内部账号接管、导出重建和恢复。

J03/J05相对于v0.2已明确收窄为内部任务；不会借旧编号重新要求客户反馈或官网发布。

## 4. 同一现实任务的成功标准

收到某摄影师一段介绍和一个作品PDF。即便没有公开授权、没有CMS账号、没有模型Key，也能在有接收依据的情况下建立内部草稿，补角色、挑作品、记录来源并在授权内部范围查到。稍后有允许的AI处理条件时，可以解析介绍并建议字段。

运营人员只需要完成“建人才→添加资料/作品→保存”的动作。来源记录、上传会话和权限可由后台串联，不强迫用户在多个数据库式菜单之间跳转。

内部候选清单是工作人员的工作成果：保存人、作品、排序、备注和待确认项。它不是一份对外访问授权，更不是客户选择的证据。未来对外分享另行设计。

## 5. 替代方案与可借鉴点

之前研究涉及Mediaslide、Syngency、Casting Networks、StudioBinder、ResourceSpace、Frame.io和Directus；它们只作为相关工作流的历史参照，不是本轮经过实际试用的采购推荐。[H-MARKET，见13]

本期仍可以借鉴：人才多角色档案、作品优先的列表、按用途展示元数据、选择清单的顺序与备注、可说明的来源。排期、会计、审片、网站同步等不因竞品存在就加入当前范围。

与自建比较的真实基线还是聊天+表格+网盘。系统应降低重复操作，而不是把一条微信沟通变成十道审批。已有成熟工具继续承担原片交付、审片和正式签约；OS记录事实引用即可。

## 6. 待验证假设

| 假设 | 当前证据 | 本期实验 |
|---|---|---|
| H01 找人和整理资料频繁重复 | 用户陈述；频次未实测 | 记录两周实际任务类型和用时 |
| H02 人/作品/项目关联能净省时间 | 设计判断 | 相同任务比较，计入核验与返工 |
| H03 小表单比全量建档更易坚持 | 设计判断 | 新建一人、补两作品；记录卡点 |
| H04 内部清单有助于交接 | 待验证 | 第二人接手5名候选，不依赖口头逐个介绍 |
| H05 AI能省事而非增加错误 | 用户明确希望接AI，质量未验证 | 四类任务分别计时与纠错，不用总体采纳率掩盖造假 |
| H06 SRVF选择性移植有净收益 | 定向源码证据，不是独立运行结果 | X1/X2/X3验证解耦与测试成本 |
| H07 团队能持续维护 | 维护人待确认 | 资料复核+一次隔离恢复演练 |

外部人才自维护意愿、客户网页选角接受度、公开作品权利覆盖、SEO/GEO效果全部移出当前实验。结果未知不阻止内部闭环试点。

## 7. 可用性要求

内部中文界面，支持手机查看与轻量录入；复杂权限和维护优先桌面。工种和城市可搜索选择，不让员工记代码。上传失败保留其他表单输入；从人才页内添加作品；AI面板就近出现，不要求先学“Agent编排”。

不得生成没有数据依据的匹配分数、收益图和业务状态。缺少报价、档期、国籍等不能由模型补齐；预算/排期筛选暂不提供。核验陈旧是提醒，不自动等于失去合作资格。

## 8. 范围优先级

当前先做可靠人工路径，再加入内部AI。与内部读写、私有素材、批量操作、数据恢复直接相关的安全要求保留。只服务于匿名读者、公开缓存、CMS双向编辑或客户身份认证的要求延期。

源材料接收允许有据临时整理；将材料发给第三方AI需独立确认用途、供应商和必要字段。“不用官网”不等于“可以把内部所有资料发给任何模型”。

## 9. 成效解释

试点的成功是可靠资料和可复用协作形成了净收益，不是表的数量或AI调用次数。系统可以长期先服务ONCE内部；将来对外展示是可选择的发展方向，不是本期必须兑付的承诺。
