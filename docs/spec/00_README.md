# ONCE｜供应商库 V1 开发基线

版本：ONCE供应商库 V1｜日期：2026-11-06｜当前范围：1,000—10,000位多职业供应商的资料、材料、作品和本人维护。本人确认直接入库，ONCE可整理纠正。详细方案见 [供应商库设计](../design/ONCE_SUPPLIER_LIBRARY_V1_20261106.md)，实际实现及未验项见 [实施记录](../release/SUPPLIER_LIBRARY_V1_IMPLEMENTATION.md)。

## 1. 这版做什么

**把人和资料管理起来：本人登录 → 上传 PDF/图片 → AI 解析预填 → 本人调整确认 → 进入 ONCE 内部供应商库 → 持续维护和查找。**

第一版面向 1,000—10,000 位模特、导演、编剧、摄影师、灯光师、剪辑师、调色师等专业人士。一人多职业，共用一个 Person 和独立 TalentAccount。本人确认即可入库，ONCE 随时整理纠正；首次认领已经存在的其他来源档案仍要核对归属。

PDF 的文字、页码、图片和作品候选进入系统数据流程。原件保留作出处；只保存附件不满足本版要求。AI 建议先进入可编辑草稿，未经本人选择和确认不改正式资料。没有模型配置时，本地 PDF 提取和手工维护仍可使用。

## 2. 发布范围与非目标

当前交付 H5、本人资料、私有材料处理、作品和内部查找，复用现有 PostgreSQL、API、Worker、权限与审计。客户分享、官网、报价、档期、合同、交易和财务暂不扩展。已有底座功能保留，但不成为本轮主流程。

真实样本质量、真实认证和模型服务、物理手机及万人性能分别验收。不能把“目标 10,000 人”写成“已实测支持 10,000 人”。

## 3. 本期用户界面

供应商侧提供我的资料、保存草稿、上传和解析材料、核对建议、维护作品、确认入库及撤回同意。ONCE 侧继续使用人才库、详情编辑、作品和资料来源；不要求日常用户理解底层表结构。旧认领、代理和监护人审核入口保留。
