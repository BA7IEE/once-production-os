# ONCE Production OS｜PRD｜内部 OS 产品规格

版本：v0.3｜日期：2026-09-22｜当前范围：一期内部 OS + AI｜状态：文档已修订，产品实现和运行测试未执行

## 1. 范围和编号

这是当前唯一PRD。保留FR-01～30用于追踪，**22项在当前范围、8项明确延期**。没有复用旧外部功能编号来掩盖删除：同一需求中内外混合的部分标明收窄。当前验收为T01～T30中对应的22组；其余是DEFERRED，不是通过，也不计为一期未完成。

内部候选清单和内部中英文本属于本期；客户在线选人和官网语言版本不属于。本期不提供公开/客户HTTP入口，不做“以后可能用到”的发布模块或空表。

## 2. 当前关键旅程

**录入：** 内部账号 → 最少来源与用途说明 → 人才草稿 → 后补资料/私有文件 → 作品署名与项目关联 → 内部检索。没有文件、英文、完整个人资料也可先建草稿。

**协作：** 录入人员 → 检索 → 保存内部候选清单与备注 → 另一名有权限成员查看并继续整理。清单仅引用已有事实，按当前权限过滤，不生成客户链接。

**AI：** 选获准的来源文字/事实 → 查看最小化输入和用途 → 有界模型任务 → 对照来源和差异 → 多选字段一次确认。模型失败可以直接回手工输入；AI结果不能提升用途许可或事实核验等级。

**维护：** 修正/停用/限制 → 当前访问立即受限 → 受影响导出/AI任务失效 → 按保留决定清理 → 恢复演练仍保留安全状态。

## 3. 界面与交互

导航为工作台、人才、作品、项目、素材/资料、内部候选、AI、系统。不要同时把来源、字段证据、使用许可、上传会话都做成独立一级菜单；它们多数嵌入对象详情和当前动作。

人才页直接添加作品和资料；作品页内可上传/排序/选封面；失败不丢其他表单字段。没有AI配置时显示“未启用”，并保留同位置手工输入。系统对未知信息明确标注，不用模拟仪表盘或空商业模块填充界面。

内部主界面中文，名单及素材轻量浏览适配手机；不承诺完整移动端重剪辑或专业审片功能。

## 4. 数据与不变量

Person与登录User分开；Organization与Brand分开；Work与Project分开；Asset与物理StorageObject分开。内部合作关系来自真实项目参与，不来自“上传过作品”。

可变对象有revision；影响用途资格的状态另有protectionEpoch。普通文字更新提示衍生文本陈旧；权限/用途/隔离/删除变化影响访问。关系有外键和明确父子约束，不只检查“在同一workspace”。

原始数据、AI输入、导出、审计都由显式字段集合构造。新增内部字段不会自动进入这些派生面。具体模型/API/时序见07/08/09，只有12定义参数。

## 5. 功能需求与验收

### FR-01｜快速建档与多角色｜IN_SCOPE

一人一个Person，多工种是角色集合；人物不自动有登录账号。快速建档只要展示名/内部代号、角色、来源说明和维护人。城市、英文、作品可后补。前端提供单页入口；来源可在同一应用命令内创建，不必先跑多个管理菜单。

验收T01：同人添加摄影/剪辑两个角色后只产生一个ID；不填英文和文件仍可保存；未知不自动变成已核验。

对应：DEV-03；B01/B02；J01。状态：NOT_RUN。

### FR-02｜来源、接收依据与字段核验｜IN_SCOPE

来源记录类型、提供者声明、接收时间、文字或后续文件，以及内部接收依据和期限。先无assetId也可成立。临时整理与正式使用分开；字段核验绑定字段值、来源版本和核验人。来源不能因附件尚未上传而无法创建。

验收T02：从空库先建文字/人工来源，再建人，再上传；无循环前置；源文修改不会自动核验新值；到期有据限制访问和处理。

对应：DEV-03；B02/B03；J01/J04。状态：NOT_RUN。

### FR-03｜导入预览、去重与受控合并｜IN_SCOPE

支持有Schema的JSON及UTF-8表格文本导入预览，逐行诊断，确认后逐行事务提交。重名、同电话仅提示候选，不自动合并。合并必须显式决定冲突，不合并账号，不自动扩张用途和可见范围；有无法处理的依赖时保留两条并标重复待处理。

验收T03：重复提交同一批次不重复建人；部分失败可定位；同名不误合并；旧ID只读解析；无权者不可利用预览枚举联系人。

对应：DEV-03/DEV-07；B01/B02；J01。状态：NOT_RUN。

### FR-04｜字典、状态与资料新鲜度｜IN_SCOPE

角色/城市/语言/技能/行业使用稳定code和可读标签，别名可查。字典停用保留历史；核验时间显示缺失或陈旧，不推导“有档期”。按角色显示少量专属字段，其余经Schema评审再加。

验收T04：停用角色后旧项目仍可读；90天复核提醒按参数可调；历史作品不因时间长就自动变假；尺寸未知不是0。

对应：DEV-03；B02；J02。状态：NOT_RUN。

### FR-05｜外部人才自助更新｜DEFERRED

外部自助身份与审核提交后续独立设计；当前内部代录。

T05：DEFERRED；没有当前工作包，不创建替代假实现。

### FR-06｜私有上传与文件一致性｜IN_SCOPE

使用私有存储。建立上传会话并原子预留数量/暂存预算；浏览器只写隔离键。Worker封存到新键、检查最终文件，再建立可用资产。完成上传的响应只是已接收任务，不是检查通过。最终文件不被原上传地址覆盖。

验收T06：覆盖仍有效的staging地址不能改变READY文件；MIME/大小不符、断传、重复complete、任务崩溃均不显示假成功；配额幂等释放。

对应：DEV-04；B02/B03；J01。状态：NOT_RUN。

### FR-07｜内部预览与安全衍生文件｜IN_SCOPE

内部缩略图与PDF安全预览保留相同访问范围；原件默认私有。仅执行允许的缩放/清理，保持署名；不自动裁人像或擦除版权水印。首版不做公开媒体。不能安全生成预览时可显示占位和元信息，但不能当预览已验收。

验收T07：不同权限成员访问原件、缩略图、视频Range均受保护；EXIF处理不等于清除像素中的联系方式；隔离/删除立即阻止新访问。

对应：DEV-04；B03；J01/J04。状态：NOT_RUN。

### FR-08｜作品集与真实署名｜IN_SCOPE

作品是一组有顺序、封面、描述和署名的素材；标识ONCE制作、外部作品或未知。摄影、出镜、后期贡献分别记录，不把上传人当唯一作者。资产选择必须属于当前工作空间且有可用内部用途。

验收T08：一作品可有多种贡献；外部作品和参考图不增加ONCE项目业绩；编辑顺序与封面有CAS，不造成跨作品子项错绑。

对应：DEV-05；B02；J04。状态：NOT_RUN。

### FR-09｜轻量项目、参与事实与内部复盘｜IN_SCOPE

项目只管名称、负责人、客户/品牌引用、地点与日期说明、提名/确认/实际参与、作品关系和内部复盘。参考作品和交付作品明确区分。可记录实际发生的项目，不要求先存在合同或商机。

验收T09：没有CRM/合同也能建项目；只有ACTUAL支持实际合作表述；完成项目不产生账款/锁档；内部复盘不创建公开CaseStudy。

对应：DEV-05；B02/B04；J04。状态：NOT_RUN。

### FR-10｜独立对外案例与商业展示｜DEFERRED

对外案例页面/叙事审批延期；内部项目复盘由FR-09覆盖，不预建CaseStudy表。

T10：DEFERRED；没有当前工作包，不创建替代假实现。

### FR-11｜内部用途、额外使用许可与限制｜IN_SCOPE

内部接收依据嵌入来源；额外的INTERNAL_EXPORT和AI_PROCESS各有受限许可记录，不因内部可读就自动允许。许可限定对象/字段/操作/期限；AI额外限定供应商配置身份与数据类别。未知条件/明确禁止不由AI解除。不开版权图谱或全球发布审查系统。

验收T11：无官网许可不阻碍有据内部整理；未知AI权限不发模型；已限禁止裁切的文件不能默认裁成头像；到期按当前时间判断。

对应：DEV-03/DEV-07/DEV-08；B03；J01/J05/J06。状态：NOT_RUN。

### FR-12｜内部停用、期限与依赖失效｜IN_SCOPE

源依据暂停/到期、范围收窄、资产隔离、删除受限等影响用途资格的变化，要阻断新读取/任务/下载；与普通内容修改分开维护protectionEpoch。后台补清理，不靠定时器先改状态才能拒绝。不会执行官网撤回。

验收T12：暂停源或隔离文件后旧导出不可新下载；候选清单隐藏受限项；排队AI不得继续取数据；已有下载副本不承诺收回。

对应：DEV-04/DEV-07/DEV-08；B03；J06。状态：NOT_RUN。

### FR-13｜归档、保留与受控删除｜IN_SCOPE

普通归档保留允许的内部阅读；删除先预览影响、设访问阻断，再由清理任务处理正式文本、预览、AI缓存、导出和索引。必要保留的最小证据单独说明期限。不可变指普通编辑不能改，不是禁止批准删除。

验收T13：删除已入导出/AI输入的来源能找到相关派生物；旧payload可销毁留下ERASED头；不误删有独立合法依据的别处记录；不能证明影响时不假报完成。

对应：DEV-07；B03/B05；J06/J07。状态：NOT_RUN。

### FR-14｜结构化检索与证据解释｜IN_SCOPE

筛选角色、城市、语言、技能、行业、作品类型、实际合作和核验时效；查询/统计/联想同一权限条件。结果显示命中依据与未知条件，不给未校准的百分比评分。缺报价/档期则说明当前不支持该筛选。

验收T14：手工筛选与AI解析后的相同条件结果一致；无权限人才不出现在计数和联想；不以空值满足预算和档期。

对应：DEV-06；B01/B04；J02。状态：NOT_RUN。

### FR-15｜内部候选清单与协作备注｜IN_SCOPE

本期将原客户候选包收窄为内部Shortlist：选人/作品、排序、需求说明和协作备注，保存revision和编辑人；读时取当前允许的资料并提示相较加入时已更新。不建立BoardVersion/ShareGrant/客户快照。历史文件需求由FR-29受控导出承担。

验收T15：两个内部成员在各自范围协作；无权条目不泄露内容；冲突不覆盖；没有分享按钮/匿名URL/客户已确认/已预订状态。

对应：DEV-06；B01/B04；J03。状态：NOT_RUN。

### FR-16｜客户外部访问及受控分享链接｜DEFERRED

不创建客户访问凭证、分享会话、分享域和匿名媒体通道。

T16：DEFERRED；没有当前工作包，不创建替代假实现。

### FR-17｜客户在线反馈｜DEFERRED

无客户入口，因此不建在线反馈；工作人员可在内部清单记沟通备注，但不可冒充客户本人反馈。

T17：DEFERRED；没有当前工作包，不创建替代假实现。

### FR-18｜四类有界 AI 辅助任务｜IN_SCOPE

固定四任务：extract_profile、suggest_tags、draft_locale、parse_search。首版均可用已获准文字/PDF提取文本运行，扫描PDF可人工补文字；图片视觉理解暂不作为必需能力。模型无Shell、自由HTTP、数据库或自动业务写权限。

验收T18：四任务输入输出都有Schema；来源缺失/虚构事实拒绝；没有AI Key时手工路径正常；不根据照片推断身份、国籍或敏感属性。

对应：DEV-08；B01/B06；J01/J02/J05。状态：NOT_RUN。

### FR-19｜有证据的 AI 建议与一次原子采纳｜IN_SCOPE

建议与事实分离。PENDING时可勾选多个字段，然后一次原子确认；该次提交后整份建议APPLIED并记录已选/丢弃项。不支持一份APPLIED建议反复继续采纳。必须检查当前权限、依赖和源revision。

验收T19：AI运行期间人工改城市，旧提议不可覆盖；第一次只选城市后，另一新key再接受余项被拒；同key安全重放；删除建议不影响已确认业务事实。

对应：DEV-08；B02/B06；J05。状态：NOT_RUN。

### FR-20｜AI 数据、配置、预算及未知请求｜IN_SCOPE

外部调用先最小化输入、核实用途和Provider配置，再原子预留上界费用。发送前持久记录Attempt的MAY_HAVE_EXECUTED；结果或计费未知则停止自动重试并保留预留额。模型切换不沿用另一供应商许可。没有费率/预算/用途证据则功能关闭。

验收T20：供应商收到请求后杀Worker，不自动生成第二次调用；并发预算不超预留上限；未知费用不因FAILED被释放；停用/恢复后旧任务不自动重发。

对应：DEV-08；B03/B06；J05/J07。状态：NOT_RUN。

### FR-21｜官网公开投影与发布审核｜DEFERRED

不做PublicProjection、公开审批或发布快照；内部字段白名单仍由FR-26/20/29执行。

T21：DEFERRED；没有当前工作包，不创建替代假实现。

### FR-22｜内部中英文本及来源版本｜IN_SCOPE

这里只做内部人物/作品/项目中英文说明。语言文本独立revision，记录依赖事实版本；可以手工写或接受AI草稿。另一语种或事实更新后提示需要复核，不静默覆盖。没有公开批准、站点URL、hreflang或sitemap。

验收T22：中文更新后英文文本原样保留但提示陈旧；英文可单独保存；无官网账号/域名/API仍能完成全部内部文本任务。

对应：DEV-05/DEV-08；B02/B06；J05。状态：NOT_RUN。

### FR-25｜SEO/GEO 页面与搜索标记｜DEFERRED

无SEO/GEO内容生产、Schema、hreflang、sitemap或流量验收。

T25：DEFERRED；没有当前工作包，不创建替代假实现。

### FR-26｜内部账号、权限及运行主体｜IN_SCOPE

单ONCE工作空间。服务端会话、管理员创建与激活、停用、密码重置、角色及敏感权限。首次Owner由空库本地CLI创建，不存在默认密码和公开注册。内部Worker用固定任务能力，不先建服务账号管理/OAuth/SSO产品。

验收T26：停用账号下一请求拒绝；改变权限使旧会话失效；非空库不能重新bootstrap；人有资料不自动能登录；字段白名单由后端执行。

对应：DEV-01；B03/B05；J07。状态：NOT_RUN。

### FR-27｜审计、敏感读取与变更记录｜IN_SCOPE

业务写与最小审计同事务，敏感联系信息读取、导出、用途确认、删除、配置变化和AI采纳另有明确事件。记录谁在什么范围做了什么，不记录密码、密钥、签名URL或任意完整before/after。

验收T27：回滚事务没有成功审计；错误/拒绝进入安全日志；敏感哨兵不出现在应用/代理日志；可追溯提议与人类采纳。

对应：DEV-01；B02/B03；J06/J07。状态：NOT_RUN。

### FR-28｜本地幂等与持久任务｜IN_SCOPE

PostgreSQL命令回执与持久任务；API/Worker不同进程，同仓代码。重放回执先于对新命令检查expectedRevision；任务至少一次，需要各处理器重复安全。租约只约束本地确认，不声称能消除外部AI重复计费。

验收T28：同key同载荷返回原安全结果；不同载荷409；新key旧revision冲突；失去权限不能借旧回执取数据；旧租约不能确认新任务。

对应：DEV-02；B05；J01/J05/J07。状态：NOT_RUN。

### FR-29｜内部 JSON 导出、重建与迁移｜IN_SCOPE

本期交付有Schema的内部JSON与媒体身份清单，用于有权限的迁移/重建，不是客户资料包。冻结精确记录、字段、源保护版本和许可；执行及下载逐依赖复查，任一失效整份旧导出拒绝，重新生成。CSV下载、PDF客户排版与公开媒体打包延期。

验收T29：旧导出生成后失去一行/字段权限，下载拒绝；重建10人3作品1项目关系；不包含会话/密钥/未选字段；备份由独立运维路径处理。

对应：DEV-07；B05；J07。状态：NOT_RUN。

### FR-30｜部署、备份、恢复及维护交接｜IN_SCOPE

内部API、Worker、数据库、私有存储与管理前端独立部署；不配置CMS、分享域、公开桶也能启动。备份同时考虑关系、媒体清单和密钥恢复。旧库恢复先关闭普通访问与AI/导出，核对已删/停用/用途变化后放行。

验收T30：干净环境与恢复环境完成手工内部旅程；AI服务离线不使核心ready失败；恢复缺口不能默认旧许可有效；旧任务不自动发模型。

对应：DEV-09/DEV-10/DEV-11；B05；J07。状态：NOT_RUN。

## 6. 可验收的“OS底座”

现在实现稳定ID/版本、有限角色与字段权限、来源依据、私有文件、任务/回执、审计、清理、导出和恢复。以后各业务模块经领域接口引用这些事实，不允许直接把内部资料序列化当公共API。

不承诺“以后绝不会改表”。未来确有业务新规则时通过兼容迁移增加模型；已有身份和来源不重新建一遍。接口/模型的稳定性由行为测试和依赖边界支撑，而不是把所有未来表先建空。

## 7. 非功能与验收边界

功能验收覆盖正常、无权限、字段越权、范围变更、旧版本、重复命令、任务崩溃、对象缺失、无AI、未知计费、旧备份恢复。负载样本与目标见12，全部是待测目标，不是已有SLA。

本期真实存储、AI等供应商能力按各自使用边界实测；本地假Provider不算真实供应商通过。没有官网域名、CMS凭证、公开授权、客户访问或SEO数据，不影响本期内部验收。

## 8. 明确不做的未来连接

CRM/报价/商业合同/排期/财务，以及官网/客户分享/自助门户，只有范围记录与稳定实体引用要求。当前不创建这些业务表/路由/状态机/部署变量。旧文档出现的发布gen、CMS墓碑、公开媒体清单等不会由开发者凭记忆带回一期。
