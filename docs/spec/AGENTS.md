## 当前产品

只做内部人才、作品、轻量项目、素材、内部候选、内部AI与必要维护。AI是一期工作，但关闭AI仍能做核心业务。无客户分享/反馈/自助门户，无CMS/官网/SEO/GEO，无CRM/财务/合同/排期/报价。

禁止生成这些延期模块的空表、菜单、路由、SDK、Worker、凭证配置、PublicProjection或“先占位”。未知未来需求只留稳定ID、域接口和版本原则；不要先建通用规则/工作流/插件平台。

## 开工

从DEV-00合成数据开始。写前说明本工作包、FR/T/AT、计划路径、依赖、迁移及不做范围。只在获准来源范围移植SRVF，不改SRVF主仓、不带真实救援资料/secret，不把旧AGENTS门禁整份搬来。

每个切片交付实际前端旅程+接口+权限+失败处理。不要先生成几十个CRUD让用户自己拼流程。来源允许先无文件，人才允许缺字段；没有官网许可也可以在有内部依据时保存草稿。

## 不可绕过

当前范围/字段由后端判定，列表/计数/预览/AI/导出同边界。封存final后再检查。回执命中先于新命令CAS，秘密不进回执。AI建议不是真实事实；MAY_HAVE_EXECUTED未知请求不盲重发；多选一次原子采纳。导出旧文件逐依赖复查。删除可销毁历史敏感payload，恢复缺口必须隔离核实。

文档检查不是运行测试；Mock不是供应商实测；NOT_RUN不能写PASS。代码、Schema、OpenAPI、真实命令/日志和恢复报告才是后续实现证据。架构文档中的示例不是已存在的接口或CLI。
