## 当前产品

当前先完成“邀请本人 → 登录 → 上传 PDF/图片 → 提取文字和图片 → AI 结构化建议 → 本人调整并确认 → 直接入库 → ONCE 查找和纠正”的闭环。沿用内部管理底座；H5 为首个入口，小程序复用同一领域服务。职业包括导演、摄影、编剧、灯光、剪辑、调色、模特等，不默认把所有人归为模特。

客户分享、官网、参考报价、排期、交易和财务不属于这次第一版交付。旧 A/B/C 与 PR-00–08 仅作历史路线图；不得以这些旧门槛阻止当前已经授权的 PDF 解析和本人直接确认。真实模型、认证通道、真实样本及万人性能分别记验收，不以合成数据或模拟服务代替。

## 开工

先核对最新 main/HEAD、打开的相关 PR 和 CI，再按本轮设计的 P0—P5 记录进度，沿用 DEV 已实现底座。写前说明本工作包、FR/T/AT、计划路径、依赖、迁移及不做范围。只在获准来源范围移植SRVF，不改SRVF主仓、不带真实救援资料/secret，不把旧AGENTS门禁整份搬来。

每个切片交付实际前端旅程+接口+权限+失败处理。不要先生成几十个CRUD让用户自己拼流程。来源允许先无文件，人才允许缺字段；没有官网许可也可以在有内部依据时保存草稿。

## 不可绕过

当前范围/字段由后端判定，列表/计数/预览/AI/导出同边界。封存final后再检查。回执命中先于新命令CAS，秘密不进回执。AI建议不是真实事实；MAY_HAVE_EXECUTED未知请求不盲重发；多选一次原子采纳。导出旧文件逐依赖复查。删除可销毁历史敏感payload，恢复缺口必须隔离核实。
