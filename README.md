## 已实现的第一条路径

空库专用 CLI 初始化管理员；新成员通过一次性凭证自行设置密码；创建带有内部整理依据的来源与人才；同一人可以有多个制作角色；联系方式另行授权、加密存储；来源到期或暂停后，相关资料的下一次读取被拒绝。有限 JSON 导入先预览，选择行后返回 `202 ACCEPTED`，独立 Worker 逐行处理。

管理前端包含登录/激活、概览、人才、来源、导入、成员与范围、字典、审计、修改密码。2026-09-23 已用本地合成数据跑通登录、协作范围、建档、核验、导入、来源停用和退出；完整浏览器异常路径仍待验收。

## 验证边界

实际执行的核心/客户端传输/回环 HTTP 测试使用合成数据和测试专用 MemoryStore；生产适配器只连接 PostgreSQL，不会降级到 MemoryStore。完整证据在 [artifacts/core-test-report.json](artifacts/core-test-report.json) 与 [artifacts/verification.json](artifacts/verification.json)。

没有默认账号密码，没有生产密钥、数据库备份或预构建镜像。真实依赖锁文件已纳入本包；本地生成的 `node_modules`、`.env` 和 `.secrets` 不属于交付内容。所有说明文档均为 Markdown。

隔离环境验证结果见 [测试报告](docs/release/TEST_REPORT.md)。正式部署仍须完成剩余功能、恢复/删除能力及对应验收。

## 包完整性

根目录的 `MANIFEST.sha256` 覆盖源码、说明和交付时证据文件（不含清单自身）。可在项目根运行 `sha256sum -c MANIFEST.sha256` 核对。重新执行测试会更新证据文件，后续发布需重建清单；该校验不是代码签名或安全认证。
